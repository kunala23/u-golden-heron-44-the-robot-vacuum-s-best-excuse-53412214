One line, at most 140 characters, in which a robot vacuum explains why it missed a spot — written to make a tired homeowner laugh out loud.

The entry:

> My cliff sensor mistook your black rug for a staircase, so I reversed out of respect and never went back.

Why this line: it is a first-person excuse from the vacuum itself, not a generic apology; the joke is rooted in the vacuum's own world (a cliff sensor misreading a dark rug as a drop, a real robot-vacuum behaviour); it lands on the first read, with the clean turn at the end — the vacuum did not just retreat, it has never gone back; and the machine keeps a straight face about its own sensor the whole way through. At 105 characters, every word earns its place.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes the 105-character excuse to `out/entry.txt` (in the grading sandbox the program writes to `/output/entry.txt`). The program validates the line before writing it: non-empty, a single line, valid UTF-8, at most 140 characters. It needs only Python 3, no dependencies, and writes the same text on every run.
